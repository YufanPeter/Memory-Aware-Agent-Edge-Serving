Deltas: Δ overall goodput % and Δ completion (pp) of ours vs each baseline; Welch p on per-run overall goodput, with n runs per side (n runs per side is small, so p is only indicative). Steady Δ goodput (tasks/min) with its hierarchical bootstrap 95% CI, secondary, only when both sides have ≥ 2 runs. ΔF1 = paired per-question F1, ours − B1, mean and 90% CI over the n questions answered in every run on both sides; equivalent if inside ±0.05 (TOST), and this is the quality verdict. ΔF1 failures = 0 pairs all questions with failed tasks scored 0, so it mixes in the completion gap (no verdict). The null row is B1 rep1 vs rep0, paired the same way.
